# Clínica Manhattan - Sistema de Gestão Odontológica

## Qual problema o sistema resolve?
Clínicas pequenas controlam agenda, pacientes e atendimentos em papel ou planilhas, o que gera conflito de horários, perda de informação e faltas sem aviso. O sistema centraliza tudo em um só lugar.

## Quem utilizará o sistema?
- Recepcionista/secretária: cadastra pacientes e marca consultas.
- Dentistas: consultam a agenda e os pacientes.
- Administrador/gestor: acompanha o resumo da clínica.

## 5 principais funcionalidades
1. Cadastro e login de usuários
2. Cadastro de pacientes
3. Agendamento de consultas, com bloqueio de horário repetido
4. Lista de consultas agendadas
5. Painel com resumo (total de pacientes e consultas)

## Telas
- `index.html`: tela inicial
- `login.html`: login e cadastro
- `sistema.html`: tela principal do sistema

## Como executar
Abra o arquivo `index.html` no navegador.
